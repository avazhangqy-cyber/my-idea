# 匿名日记本

一个为高中生提供匿名、非判断式自我认同支持的 AI 反思日记原型。用户先完成前测，再匿名输入一句困惑；网页会透明地把困惑整理成一篇匿名日记，让用户像读别人的故事一样重新看见自己的处境，最后用同样的后测题观察感受是否变化。

## 上线地址

https://my-idea-topaz.vercel.app/

## 本地打开方式

这个项目是一个静态网页，不需要安装依赖或运行构建命令。

1. 直接双击 `index.html`，用浏览器打开。
2. 或者在编辑器里用 Live Server 打开 `index.html`。

## 项目文件

- `index.html`: 网页主入口，也是 Vercel 部署的页面。
- `spec.md`: MVP 计划，说明项目目标、核心流程、反馈收集方式和成功标准。
- `research/`: 研究资料整理，包含研究问题、资料来源、摘要和数据表。

## MVP 功能

- 展示匿名和隐私说明。
- 让用户完成同一组 5 题前测和后测。
- 让用户选择或填写一个困惑方向。
- 明确说明 AI 匿名日记是整理生成，不是真人投稿、搜索结果或心理咨询。
- 允许用户把本次生成的匿名日记保存到当前浏览器里的“我的匿名日记本”。
- AI 整理后的匿名日记会作为匿名记录保存，用于后续分析；用户仍可选择是否保存到自己的本地日记本。
- 收集匿名前后测变化和 1-2 个开放反馈。
- 不收集姓名、学校、联系方式或精确位置。
